# Infra Evidence Platform — Code Cubicle Field Inspector Build

An infrastructure evidence platform built for field inspectors working in low-connectivity areas across regional India.

## Repositories & Build Structure

1. **`shared/`**: 15 hand-authored & generated infrastructure site inspection dataset ([`shared/dataset.json`](file:///Users/Deadeye/Desktop/Projects/Infra%20Evidence%20Platform/shared/dataset.json)) and 30 local royalty-free stock photos ([`shared/photos/`](file:///Users/Deadeye/Desktop/Projects/Infra%20Evidence%20Platform/shared/photos)).
2. **`cloudinary-infra-platform/`**: Next.js 14 App Router project powered by Cloudinary SDK, AI Auto-Tagging, `react-compare-slider`, shadcn/ui, and dynamic image transformations.

## Quick Start
```bash
cd cloudinary-infra-platform
npm install
npm run dev
```

See [`cloudinary-infra-platform/README.md`](file:///Users/Deadeye/Desktop/Projects/Infra%20Evidence%20Platform/cloudinary-infra-platform/README.md) for technical architecture details.
